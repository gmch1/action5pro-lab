# 故障恢复清单

## 设备停在 9008

1. 不继续写入，不执行擦除或切槽。
2. 确认供电、电池和 USB 连接稳定。
3. 重新运行只读 `doctor`/`scan`，确认 GPT 仍可读取。
4. 读取目标分区并与写前、写后哈希比较。
5. 按“先 `devinfo`、后 ABL”的顺序恢复原始备份，每步完整读回。
6. 断开 EDL 后冷启动，不在同一会话追加其他实验。

## FACTORY 模式能启动但 USB ADB 消失

标准 `adb tcpip` 会重启 `adbd`，某些构建可能暂时不再提供 USB transport。优先：

1. 停止继续网络实验；
2. 保持设备供电，重新插拔数据线；
3. 若仍不可见，正常重启相机；
4. 再检查 USB 枚举和 `adb devices -l`；
5. 必要时回到 9008 恢复启动配置。

临时 Wi-Fi 配置位于 `/tmp` 时，重启后会自动消失。

## 能启动但相机功能异常

记录异常发生的拍摄模式、分辨率、帧率、HDR/增稳状态和持续时间。采集
`dmesg`、相机日志、DMA-BUF/CMA 和内存快照。不要先修改 2.7 GB 相机预留区；
该区域不足可能只在高负载拍摄时表现为丢帧、黑屏或服务崩溃。

## 恢复完成的判定

- 能稳定冷启动；
- 前后屏、触控、拍照和录像正常；
- 存储卡和内置存储可读写；
- USB 模式正常；
- 目标恢复分区的完整哈希等于原始备份。
